# Mail provider implementation status

The SMTP transport boundaries and Docker built-in/direct mail paths now exist.
For supported modes, setup commands, external-gateway verdict integration, and
operational limits, use the [mail provider guide](MAIL_PROVIDERS.md).

Cloudflare-native inbound adapters, provider HTTP APIs, supplier feedback
webhooks, and Microsoft 365 OAuth/Send As integration remain future work. See
the [mail backend roadmap](ROADMAP.md#mail-backends--provider-flexibility).
